      question => why can't we have a static inside of a non-static, when the vica versa is true. 
      answer = > this is because of 3 things 
                                   |----Lifespan MisMatch => Static data members lives till the entire lifetime of the program(java program), from the point of the class getting loaded till the program termination, whereas the non-static data members are destryed from the memory as soon as they are done executing.
                                   |----As per the definition, static data member are attached to the class itself and not to any instance of the class
                                   |----Scope rule, static data members can only be nested directly inside of the class and not inside of the local scope of non-static member.

-> Static block => A static block also known as static initialuzation block of code is used to initialize static variables, This static initialization block is loaded into the memory only once, when the class is loaded into the momory. 
         characteristics of static block : = > 
             |---- execution timing => it run automatically the very fisrt time the class is loaded by the JVM, This happens before any object of the class is created 
             |----order of execution => if a class have mutiple static members, then they execute in the exact order in which they appear in the code. 
             |----No access to instances => Just like any static data-member which belongs to the class, these static initialization block aslo can't access the instance variables, or use "this" keyword.
             |----Static initialization blocks don't return anything. (can't return anything)
         example for static block initialization : 
            class Main{
                public static int number1 = 10 ; // number1 being a static variable who's value is already initialized. 
                public static int number2 // number2 being a static variable who's value is not initialized 
                static{
                    number2 = number1*5 ; // this is initialize the number2 static variable
                 }
             }

         question =>  What more are the usage/purpose of static initilazation block ? 
         answer => As we know static initialization blocks are executed as soon as class is laoded in JVM, meaing it can handle all the necessary tasks that is required before executing the java class code
